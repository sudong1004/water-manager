# 정수기 고객관리

Next.js 15 + React 19 + TypeScript + Tailwind 4. 데이터는 `data/*.json` 파일에 저장됩니다.

## 실행
```
npm install
npm run build && npm start     # http://localhost:3000  (같은 와이파이 폰: http://PC주소:3000)
# 개발: npm run dev
```

## 메뉴
- 🏠 홈: 방문 예정 · 필터 교체 임박/지연 · 미수금 · 최근 등록 · 지역별 고객 수
- 👥 고객: 검색, 지역(시·구 → 동) 필터, 지역순 그룹 보기, 미수금만 보기, 신규등록/수정/삭제, CSV 저장
  - 고객 상세: 정보 / 수납 / 이력 탭, 전화·문자·지도
- 💰 수납: 월별 수납 내역, 미수금 고객 목록
- 📥 가져오기: 월별 엑셀(.xls/.xlsx) 업로드 → 미리보기(신규/변경/동일/오류) → 반영

## 데이터 파일
| 파일 | 내용 |
|---|---|
| customers.json | 고객 기본정보 + 필터(엑셀 원천) |
| payments.json | 수납/청구 기록 (직접 입력) |
| records.json | 방문·상담·AS·특이사항 이력 (직접 입력) |
| imports.json | 엑셀 가져오기 기록 |

## 엑셀 가져오기 규칙
- 관리번호로 기존 고객을 찾음. 없으면 신규, 있으면 엑셀 값으로 기본정보 갱신
- 엑셀에서 비어 있는 칸은 기존 값을 지우지 않음
- 필터: 엑셀의 교체주기를 반영하되 최근 교환일은 더 최근 날짜를 유지(앱에서 교환 완료 처리한 기록 보존)
- 수납·이력은 별도 파일이라 절대 덮어쓰지 않음
- 파일 내 관리번호 중복 / 고객명 없음은 오류로 표시하고 제외
